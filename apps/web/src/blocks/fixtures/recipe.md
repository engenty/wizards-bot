# Flatbread

Makes six. The dough rests for an hour, so start early
and do something else meanwhile.

| Ingredient | Amount |       Note        |
| :--------- | -----: | :---------------: |
| Flour      |  500 g |       plain       |
| Water      | 320 ml |     lukewarm      |
| Salt       |   10 g |                   |
| Yeast      |    3 g | dry, or 9 g fresh |

## Steps

1. Mix everything and knead for ten minutes.
2. Let it rest, covered.
3. Bake each one for two minutes on a hot pan.

```sh
# a timer for the rest
sleep 3600 && say "The dough is ready"
```

Costs about 1 \* 2 = 2 euros, give or take.
